# 🤝 Contributing to SyncMiles

Welcome! Here's how to collaborate effectively on this project.

## 🧭 Branching Strategy

- `main`: stable release branch (protected)
- `develop`: integration branch (protected)
- `feature/<module-name>`: work here (e.g., `feature/location-screen`)

🚫 Do not push directly to `main` or `develop`. Use Pull Requests.
